# Vanilla Product Experience v1.0.0

**First project-level release.**

Vanilla Product Experience (VPE) is a zero-build product-experience runtime built with plain HTML, CSS and JavaScript. The bundled Cursor 3.x site is the Reference Demo used to exercise the complete stack at realistic product-content density.

## Highlights

- **Template Core** — bilingual static pages, themes, Command Palette, Feature Matrix, simulator, ROI, pricing and comparison components.
- **Real Liquid Glass** — geometry-derived displacement maps, SVG `feDisplacementMap`, shared lenses and cross-browser content-copy refraction.
- **Ambient Interaction Field** — WebGL2 particles, Canvas2D fallback, pointer wake, scroll energy and glass mirror bridge.
- **Site Motion** — interruptible spring physics, FLIP layout continuity, number motion, timeline progress and section choreography.
- **Product UI / Art Direction** — Mobile Island navigation, responsive typography, proof/media/conversion surfaces and light-mode direction.
- **Experience Integration** — zoom/window resilience, readable Feature Matrix filtering, PWA cache integrity and responsive hardening.
- **Accessibility** — keyboard-first controls, native input preservation, reduced motion and reduced transparency paths.

## Project identity

- Project version: `1.0.0`
- Public facade: `window.VPE`
- Compatibility aliases: existing `Cursor*` globals remain supported in v1.
- Reference content: Cursor 3.x / September 2026 demo data.

## Browser policy

- Chromium: real backdrop-displacement path.
- Safari / Firefox: content-copy SVG displacement path.
- WebGL2 unavailable: Ambient falls back to Canvas2D.
- Touch/coarse pointer: reduced visual budget with native interaction targets preserved.

See [`../BROWSER_SUPPORT.md`](../BROWSER_SUPPORT.md) for the detailed support matrix and QA boundaries.

## Known boundaries

- Safari/Firefox native visual tuning should still be checked on the target browser versions before claiming pixel-identical rendering with Chromium.
- Dynamic video/canvas content is not DOM-rasterized into the Safari/Firefox content-copy renderer by default.
- The Reference Demo social preview currently uses the project icon; forks should provide a dedicated 1200×630 image.
