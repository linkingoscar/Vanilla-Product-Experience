# Changelog

All notable **Vanilla Product Experience** project changes are documented here. Project-level semantic versioning begins at v1.0.0.

## [1.0.0] - 2026-09-04

### Project identity

- Renamed the project to **Vanilla Product Experience (VPE)**.
- Reframed Cursor 3.x as the high-fidelity **Reference Demo** rather than the repository identity.
- Added the neutral `window.VPE` public facade while retaining historical `Cursor*` globals as v1 compatibility aliases.

### Experience runtime

- Stable zero-build Template Core with bilingual pages, themes, PWA, SEO and accessibility foundations.
- Real Liquid Glass displacement/refraction with Chromium backdrop and Safari/Firefox content-copy renderer paths.
- WebGL2 Ambient Particle Interaction Field with Canvas2D fallback and Glass mirror bridge.
- Site Motion system with interruptible springs, FLIP layout continuity, continuous number motion and scroll choreography.
- Product UI / Art Direction system with Mobile Island, typography roles, proof/conversion surfaces, media framing and Light Mode direction.

### Release hardening

- Hardened Liquid Glass containing blocks and direct-text foreground layering.
- Reworked Hero/mobile composition, Feature Tabs, navigation capacity and language-switcher resilience.
- Corrected geometry-based navigation active state for document/nav ordering differences.
- Fixed Feature Matrix content clipping by making natural readable height an invariant during filter transitions.
- Completed runtime cache invalidation/version alignment for the corrected layout-motion helper.

### Documentation and governance

- Added architecture, browser support and version/cache policy documentation.
- Added contribution rules and PR checklist.
- Promoted integrity checks from a Liquid-Glass-specific workflow to project-level experience integrity.
