Cursor 3.x Architecture

Highlights at a Glance

A brand new Agent-first interface elevating multi-agent orchestration to a first-class citizen, preserving native developer depth.

Agents Window Unified Workspace

Unified sidebar to run and monitor multiple agents in parallel across local, worktree, cloud, and SSH environments. Integrates seamlessly with iOS/iPadOS, Slack, GitHub, Linear, Jira, and Teams.

  • Native multi-repo context awareness and reasoning
  • Instant local ↔ cloud execution handoff
  • Retains full VS Code ecosystem for fine-grained editing

Design Mode Visual Feedback

Inspect, annotate, and select UI elements directly inside the built-in browser to give immediate visual context to agents with ⌘⇧D and ⌘L.

Agent Tabs Grid View

View parallel sessions side-by-side. Leverage /multitask for asynchronous subagent execution to split complex tasks into concurrent branches.

Auto-review Smart Verification

New in 3.6: Reduce approval fatigue. Allowlisted commands execute immediately, sandboxed tasks run safely, and high-risk actions are verified by classifier subagents.

/loop Autonomous Schedules

New in 3.5: Run prompts on recurring schedules or until assertions pass. Ideal for persistent monitoring, deployments, and continuous testing.

MCP & JetBrains ACP Ecosystem

Full Model Context Protocol compliance. Marketplace features hundreds of MCPs and Skills. Support for JetBrains IDEs via open Agent Client Protocol (ACP).
