Cursor 3.x 核心架构

亮点速览

全新 Agent 优先界面，将多智能体编排提升至一等公民，兼具极速原生编码与深度协同验证。

Agents Window 统一工作区

全新 Agent 优先界面，支持本地、worktree、云端、SSH 多环境并行运行。侧栏统一管理所有 Agent，包括从移动端 iOS/iPadOS、Web、Slack、GitHub、Linear、Jira、Teams 发起的任务。云 Agent 自动生成验证演示与测试录屏。

  • 多仓库原生上下文支持与联动
  • 本地 ↔ 云端环境毫秒级无缝切换
  • 保留完整 VS Code 生态，随时切回经典编辑

Design Mode 视觉反馈

在内置浏览器中直接标注、框选 UI 元素，精准反馈给 Agent。支持快捷键操作：⌘⇧D 切换、⇧拖拽 框选区域、⌘L 注入上下文对话。

Agent Tabs 网格分屏

多会话并排或网格查看，方便横向对照不同模型方案。配合 /multitask 异步子代理并行处理，自动将大需求拆解并同时执行。

Auto-review 智能审查

3.6 核心特性：告别烦琐的审批疲劳。白名单命令立即执行，沙盒环境安全运行，高风险变更由专属分类 Subagent 自主审查把关。

/loop 循环守护任务

3.5 自动化更新：按周期或事件触发重复执行，直至目标断言达成。非常适合持续测试监控、部署流水线探测等长任务。

MCP 结构化输出 & 跨 IDE 生态

全面兼容 Model Context Protocol。Marketplace 汇聚海量 MCP、Skills 与 Hooks。支持通过 Agent Client Protocol (ACP) 直接在 JetBrains 全系 IDE 中使用 Cursor Agent。
